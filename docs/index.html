轻账本 隐私政策

更新日期：2026-09-09
生效日期：2026-09-09
隐私摘要
  • 不收集任何个人信息
  • 数据仅保存在本机应用沙箱，卸载即删除
  • 不发起任何网络请求，可完全离线使用
  • 未接入任何第三方 SDK，无广告、无统计、无推送

欢迎你使用「轻账本」（以下简称"本应用"）。在开始使用前，请你仔细阅读本政策。本政策用于说明本应用如何处理（以及为什么不处理）你的信息。

我们郑重声明：本应用不收集、不上传、不共享任何用户个人信息。这不是一句口号，而是由本应用的实现方式决定的——本应用没有服务器、没有账号体系，也不具备联网能力。

开发者/运营者：刘昊岩。本应用由该主体独立开发并运营，不委托任何第三方收集或处理用户信息。

1. 信息收集：零收集

本应用不收集你的任何个人信息，包括但不限于：姓名、手机号、邮箱、位置、通讯录、相册、设备标识符、使用行为记录等。本应用不包含任何形式的用户画像、行为分析或数据上报。

你在本应用中记录的账目、账户、分类、备注等全部内容，均由你本人主动录入，仅用于在本机呈现给你自己。

2. 数据存储：仅保存在本机沙箱

你的全部数据（账目、账户、分类、预算、设置项）仅保存在本机为本应用分配的应用沙箱目录中。该目录为系统级私有目录，其他应用无法读取。

卸载本应用即删除全部数据，且不可恢复。如需保留，请在卸载前通过应用内的导出功能自行备份数据文件，导出的文件由你自行保管。

3. 网络说明：不发起任何网络请求

本应用不发起任何网络请求，不申请网络相关权限，不具备联网能力，可 100% 离线使用。

不联网是本应用的刻意设计，而不是功能缺陷：正因为没有网络通道，你的账目数据在技术上就不可能被发送到任何地方。

4. 权限说明：默认零权限

本应用默认不申请任何系统权限。安装和使用的全过程中，系统不会弹出任何权限申请弹窗。

本应用不申请也不使用位置、相机、麦克风、通讯录、存储、日历、传感器等任何敏感权限。涉及选择图片或保存文件的场景，均通过系统提供的免权限选择器（由系统弹出、由你手动确认）完成，本应用只接收你明确选择的临时访问授权。

由于默认零权限，也就不存在"拒绝某项权限会影响使用"的情况——你可以在系统设置中查看本应用的权限列表进行核验。

5. 第三方 SDK：未接入

本应用未接入任何第三方 SDK，包括但不限于广告、统计、埋点、推送、分享、支付、崩溃收集类组件。本应用不含任何第三方代码引起的对外数据传输。

本应用同时不含任何广告，也不含任何开屏推广。

6. 未成年人保护

本应用为一款面向大众的记账工具，适合 3 岁及以上用户使用。本应用不针对未成年人定向收集任何信息，也不包含面向未成年人的营销内容。未成年人应在监护人指导下使用。

7. 你的数据权利

你对自己的数据拥有完全控制权：

  • 查看与导出：你可以随时在应用内浏览全部数据，并通过导出功能生成数据文件，自行保存与处置；
  • 一键清空：你可以在应用内一键删除全部本地数据，删除后不可恢复；
  • 卸载即删：卸载本应用将同时删除本机沙箱中的全部数据。

除上述由你本人主动触发的操作外，本应用不存在任何其他数据删除或转移渠道。

8. 诊断信息导出

当你在「我的 → 导出诊断信息」中主动导出时，本应用会通过系统文件保存面板生成一份诊断 JSON。该文件只含应用版本、数据库就绪/只读状态和最近的技术运行日志；不含账目、备注、账户或分类名称、密码及密码哈希。文件只会保存到你在系统面板中选择的位置，由你自行决定是否提供给技术支持。

本政策可能随应用版本更新而调整。发生更新时，我们会在应用内以显著方式提示你查阅更新后的内容；如更新涉及处理方式的实质变化，会在应用内重新征求你的同意。更新后的政策自应用内公示之日起生效。
