# 轻账本（LifeLedger）

> 不开账号不联网，记一笔账只要 3 秒。

基于 HarmonyOS（ArkTS / ArkUI）开发的纯本地记账应用：没有服务器、没有账号体系、不发起任何网络请求，数据仅保存在本机应用沙箱，卸载即删除。

## 核心特性

- **极速记账**：中置「+」一键进入，计算器式键盘支持连续运算，默认记住上次使用的账户与分类
- **纯本地，零权限**：不联网、不上传、不收集任何信息；导入导出全部走系统选择器，无需敏感权限
- **多账本管理**：个人、家庭、店铺各建一本，首页一键切换
- **预算管家**：月度预算 + 环形进度，80% 黄色预警、超支红色提醒
- **多账户管理**：现金、银行卡、电子钱包随心添加，支持账户间转账，余额自动联动
- **统计分析**：分类环形图、排行榜、近 6 / 12 个月收支趋势折线
- **查账好手**：按天分组、按月翻阅，关键词搜索 + 多条件组合筛选
- **数据自由**：一键导出 CSV（UTF-8，兼容 Excel），全量 JSON 备份 / 恢复（带校验与恢复前警告）
- **隐私上锁**：数字密码锁，冷启动 / 后台返回均需验证
- **好看好用**：卡片化设计、蓝紫渐变主色、浅色 / 深色 / 跟随系统三种主题

## 隐私政策

本应用郑重承诺：**不收集、不上传、不共享任何用户个人信息**。

政策全文在以下四处保持一致，可随时对照核验：

1. 应用内首次启动的隐私摘要弹窗（不可跳过、默认不同意）
2. 应用内「我的 → 隐私政策」常驻入口
3. 华为应用市场（AppGallery Connect）托管的隐私声明
4. 应用安装包内的政策文件 `resources/rawfile/privacy.md`

如发现任何一处与实际行为不符，请通过客服邮箱 **3371920569@qq.com** 反馈。
